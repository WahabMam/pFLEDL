# Figure archive

PDF figures copied from the research experiment archive. Original subdirectories and alternative versions are retained. This is an archive, not a declaration that every figure is a final manuscript figure or a three-seed summary.

Reliability diagrams may depict individual runs. Values printed on those plots must not be interpreted as three-seed averages unless independently verified from the plotting inputs. Seed IDs, checkpoint-selection rules, binning, and aggregation protocols are not established by filenames alone. Raw predictions and the plotting workflow for these figures are not included in this upload.

`manifest.csv` records each original path, repository path, file size, and SHA-256 checksum. Files that differ only in capitalization have a `__case_variant_` suffix in the repository to support Windows checkouts. Original experiment files were not changed.
